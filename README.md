# DLIMS 2.1 Punjab

Driving Licence Information Management System (DLIMS) 2.1 for Punjab, Pakistan.

Official repository for the DLIMS 2.1 Punjab web portal.

## Brand Colors
- Forest/Deep Green: #0E6B32 / #146b32
- Gold: #F5B301 / #f5b400
- Navy: #0A1F44 or similar

## Features (Planned)
- License tracking pages
- E-driving license card generation (PDF)
- Admin panel
- Database integration (Neon)
- Deployment (Netlify / Vercel)

## Status
Initial setup completed. Development in progress.

Developed with support from City Traffic Police Faisalabad / Safe City Punjab.
